# Portfólio Gamificado — Aion 2

## Objetivo

Apresentar quem eu sou, minhas habilidades e redes profissionais em uma experiência inspirada no universo de Aion 2. O projeto combina um portfólio pessoal com a estética de um portal de aventureiro e elementos de gamificação.

## Construção

SPA desenvolvida com abordagem mobile first e componentes React para navegação, ficha do aventureiro, apresentação do jogo e conexões sociais.

A exploração das seções concede experiência, aumenta o nível do visitante e desbloqueia conquistas. Uma estrela secreta complementa a jornada. O progresso é salvo no navegador, sem banco de dados.

O conteúdo fica centralizado em um arquivo TypeScript, separado dos componentes. A interface inclui navegação por teclado, avisos acessíveis e suporte à preferência por movimento reduzido.

## Tecnologias utilizadas

- **Next.js 16 e React 19:** estrutura da aplicação, rotas e componentes.
- **TypeScript:** tipagem do conteúdo e da lógica de gamificação.
- **Tailwind CSS 4 e CSS:** estilos e layout responsivo.
- **Context API e hooks do React:** compartilhamento e controle do progresso.
- **Intersection Observer:** identificação das seções exploradas.
- **LocalStorage:** persistência do progresso no navegador.
- **ESLint:** verificação de qualidade do código.
